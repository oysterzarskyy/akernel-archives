# The Akernel Archives

The Akernel Archives is a joint archive of Akernel made by its original creator.

## How Akernel was Made

Akernel is a "small freestanding kernel scaffold with separate 32-bit x86 and x86-64 ELF targets. It also has an opt-in x86-64 bootable ISO target using the Limine boot protocol." it comes also in a nightly Release.
